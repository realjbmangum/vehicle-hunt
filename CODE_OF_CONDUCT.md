# Code of Conduct

## The short version

Be decent. This is a small project about buying a car; nothing here is worth
being unpleasant to a stranger over.

## What's expected

- Assume good faith. Most disagreements here are about a regex, not a rivalry.
- Critique code, not people.
- Accept that the maintainer may say no. This started as one person's tool and
  it's allowed to stay opinionated.
- Respect privacy. Don't post anyone's home address, ZIP code, email, VIN or
  dealer correspondence — including your own, by accident. Redact before you
  paste.

## What isn't acceptable

Harassment, personal attacks, discriminatory language, sexualised content,
deliberate intimidation, sustained disruption, or publishing others' private
information.

## Scope

This applies in issues, pull requests, discussions and commit messages — any
space where you're representing the project.

## Enforcement

Report problems by opening an issue, or privately via
[GitHub's security advisory form](https://github.com/realjbmangum/vehicle-hunt/security/advisories/new)
if the report itself is sensitive.

I'll read every report and respond as time allows. Depending on severity,
responses range from asking someone to edit a comment through to blocking an
account from the repository. I'll aim to be proportionate and to explain the
reasoning, but the final call is mine.
